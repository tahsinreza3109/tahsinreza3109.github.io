# Tahsin Reza - Academic Portfolio

Live site: https://tahsinreza3109.github.io

A static site with no build step: plain HTML, CSS and vanilla JavaScript.

```
index.html            all content, as five pages (About, Research, Experience, Projects, Skills & Awards)
assets/css/style.css  styles, light and dark themes
assets/js/main.js     page switching, theme toggle, filters, figure lightbox, count-up stats
assets/js/bg.js       the drifting network background
assets/img/           portrait, favicons and project figures
```

Every push to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`.
